# Team 19 — Team Agreement

## Communication
We communicate by phone and prepare the project together.
We respond within 24 hours on weekdays and call each other
for urgent issues.

## Weekly Meeting
We meet every Sunday at 19:00 (Europe/Istanbul) for 30 minutes
to review progress, discuss problems and plan the next tasks.

## Shared Responsibilities
Eren Karakaş and Semih Mertcan İçyer jointly prepare and
review the requirements, design, code and documentation.
During each weekly meeting, we agree on who edits each
document and implements each task. Both members contribute
to code and documentation.

Only one member edits a shared document at a time.
We record actual contributions in the checkpoint reports.

## Review Before a Version Tag
Before creating a version tag, each member reviews the
other member's changes and runs the project on their own
computer. We check that the code and design documents match
and that both members can explain the work.

## Unavailability
If one member cannot work for a week, they notify the other
member early. We redistribute the tasks and inform the
instructor if a deliverable is affected.
